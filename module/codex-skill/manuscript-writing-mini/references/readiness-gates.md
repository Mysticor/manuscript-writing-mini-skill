# Draft readiness
States: DRAFT_IN_PROGRESS, DRAFT_COMPLETE_WITH_AUTHOR_CHECKS,
MANUSCRIPT_DRAFT_READY, BLOCKED. READY requires complete readable manuscript,
clear story/section architecture, evidence-backed claims, actual Methods and traced
Results, produced core figures/tables, substantive captions, current verification
for used literature components, recorded rights, valid citations, terminology,
main/SI allocation and no central blocker or fabricated content. Gate D records current full-draft completion under the shared AUTO/user-decision rule. Checks do not prove semantic truth; Agent must
read entire manuscript and inspect actual assets and source verification. Include
section-level citation coverage and the fixed target/actual unique citation counts
from [citation planning](citation-planning.md) in the existing content check; report
unresolved shortfalls explicitly. A longer bibliography alone does not establish support.
Compare the planned displays with the manuscript's actual questions: check for
missing necessary visual evidence, empty schematic abstractions and redundant
panels. Inspect information and legibility at final use size; palette, file existence
or technical QA alone is insufficient. Record findings in the existing content
check, revise affected assets/briefs and refresh applicable locks before readiness.
Record planned and delivered figure/table counts for main text and SI, with reasons
for changes, in that same content check. Reconcile [display planning](display-architecture.md)
with the manuscript's actual scale, applicable journal limits and inspected comparators;
note unresolved guidance/reference gaps. Check the concrete visual requirements at final
use size. Counts or superficial resemblance do not replace scientific adequacy and
readability. No additional Gate is introduced.

Script checks paths/checksums, IDs/brief fields, selected headings/captions/callouts,
citation keys, placeholders, input linkage and gates. It cannot judge whether prose
is scientifically true. Record content_check with current content fingerprint and
signed-by-process note path/hash after actual read-through, not automatic PASS.
Missing central evidence always BLOCKED. Missing drafting/production without a
false claim of completion remains DRAFT_IN_PROGRESS. Noncentral author checks must
be individually bounded. MOCK/FIXTURE cannot emit the production-ready marker.
Passing Stage 2 is not polishing, review, final submission QA or typesetting.
