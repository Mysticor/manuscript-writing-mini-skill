# Main versus supplementary evidence
Use nature-writing/nature-shared main-text-discipline for the shortest sufficient
main evidence chain. Classify discovery, support, qualification, robustness,
heterogeneity, provenance and alternatives. Main text must retain decisive support
and conclusion-changing qualification; SI provides depth, completeness and checks.
Plan actual SI sections/displays for sweeps, extended benchmarks/full tables,
implementation, additional photos/failure cases/sensitivity/secondary analyses and
literature matrices as warranted. Do not put all evidence in main, nor all central
evidence in SI. supplementary.md is canonical with concrete citations and assets;
if none is warranted, record NOT_APPLICABLE with rationale rather than invent SI.
