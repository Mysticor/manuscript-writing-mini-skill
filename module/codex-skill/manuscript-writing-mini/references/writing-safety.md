# Writing and revision safety
nature-writing is the prose engine with task=manuscript; use its argument, section,
main-text/SI allocation, repetition and terminology rules. Preserve author language
request; journal=generic unless a real target is supplied. Journal guidance is
checked against current official sources when exact rules matter, not remembered.
Methods use actual methods/data/statistics sheets; Results use actual results_facts;
Discussion uses actual claims+limits+canon. Cite prior verified library first.
Concrete numbers require source IDs, conditions and units; unknowns use
[AUTHOR_INPUT_NEEDED: ...], [DATA_REQUIRED: ...], [SOURCE_REQUIRED: ...], [VERIFY: ...].
Central placeholders block final readiness. Explicit noncentral author-only matters
can yield DRAFT_COMPLETE_WITH_AUTHOR_CHECKS, never masquerade as full READY.

Never invent data/citations/n/parameters/experiments/significance/limitations/figure
results/author claims. Update terminology ledger for new terms/symbols/units/names.
Evaluate requested revisions first; disagree if the asserted error is absent.
Integrate real fixes naturally, not with repeated additions about the last critique.
Update affected blueprint/evidence/display links; retain previous draft versions.
No automatic nature-polishing, nature-reviewer, academic-typesetting,
latex-document-skill, publication-build, submission package or reviewer simulation.
Do ordinary completeness/consistency checks only. User must explicitly switch stages.
