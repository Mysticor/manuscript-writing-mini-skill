# Writing and revision safety
nature-writing is the prose engine with task=manuscript; use its argument, section,
main-text/SI allocation, repetition and terminology rules. Preserve author language
request; journal=generic unless a real target is supplied. Journal guidance is
checked against current official sources when exact rules matter, not remembered.
Methods use actual methods/data/statistics sheets; Results use actual results_facts;
Discussion uses actual claims+limits+canon. Cite prior verified library first.
Concrete numbers require source IDs, conditions and units; unknowns use
[AUTHOR_INPUT_NEEDED: ...], [DATA_REQUIRED: ...], [SOURCE_REQUIRED: ...], [VERIFY: ...].
Central placeholders block final readiness. Explicit noncentral author-only matters
can yield DRAFT_COMPLETE_WITH_AUTHOR_CHECKS, never masquerade as full READY.

Never invent data/citations/n/parameters/experiments/significance/limitations/figure
results/author claims. Update terminology ledger for new terms/symbols/units/names.
Evaluate requested revisions first; disagree if the asserted error is absent.
Integrate real fixes naturally, not with repeated additions about the last critique.
Update affected blueprint/evidence/display links; retain previous draft versions.
No automatic nature-polishing, nature-reviewer, academic-typesetting,
latex-document-skill, publication-build, submission package or reviewer simulation.
Do ordinary completeness/consistency checks only. User must explicitly switch stages.

## Scientific meaning and focused revision
Preserve the study object/population, independent unit versus repeated measurement,
measured versus simulated quantities, comparison baseline, conditions/time window,
units/denominators, statistical scope and causal strength. Equal numeric tokens do
not establish equal meaning. Derive Methods from executed code/configuration and
actual records; distinguish proposed work from completed work. Use existing evidence
IDs and source locations rather than creating another fact ledger.

Discussion should explain what the actual finding supports, how it agrees or differs
from specific verified prior work, and what that comparison changes in interpretation
or use. Include concrete limits and unresolved questions where supported. Do not
repeat Results, turn correlation into mechanism, or force every paragraph into a
fixed template. Interpretation beyond the tested conditions must be qualified.

Compare external advice with the current manuscript and source evidence before
editing, including possible extraction artifacts or outdated versions. Preserve
accepted author decisions and deletions in the existing plan/resume/revision record;
do not restore deleted claims elsewhere without new evidence and a stated reason.
If an accepted decision conflicts with evidence, surface the conflict for resolution
instead of silently reinstating or endorsing an unsupported statement.

Design reference: https://github.com/i386345669/nc-manuscript-craft (reviewed 2026-10-21).
These rules are adapted to the existing staged workflow; no upstream prose engine,
new ledger or continuous whole-manuscript execution is introduced.
