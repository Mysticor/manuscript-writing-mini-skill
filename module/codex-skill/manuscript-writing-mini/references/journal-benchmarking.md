# 期刊全文对照

目标期刊和文类明确后，用两组真实发表论文校准正文体量、图表、引用及视觉表达：目标期刊约10篇；同领域、同文类、水平相近的其他期刊合计约10篇。两组去重且不重叠，默认各以10篇为获取目标，允许有依据的小幅浮动；不能用两三篇范例宣称完成两组对照。尚未选刊时沿用目标未定状态，不代替用户选刊或为每个候选刊各下载20篇。

先说明选样依据，再选论文。匹配研究问题/方法、文章类型、正文体量与证据规模，近期论文为主，避免只挑图多、引用多或容易下载的文章。同行期刊尽量来自多个刊物；“水平相近”结合领域定位、读者、研究贡献及验证要求，若采用分区/指标需核对年份和来源，不能只凭影响因子或名称判断。只有用户方向已确定时才批量获取；复用已有选择，不为常规补充重复询问。

优先复用蓝图交接中的 `01_target_journal_profile.md`、`10_key_paper_exemplars.md`、原文和获取记录，只补缺失或不再可比的项目。按[工具适配](adapters.md)实际获取完整PDF，或含正文、图表及参考文献的完整HTML存档，核对题名/DOI/期刊/版本及文件可解析性；登录页、错误页、摘要和题录不计为已下载。记录来源、获取日期、项目内原件相对路径和SHA-256。只获得网页访问但没有可核验原件时如实记录，不声称下载成功；不把作者接受稿的页数当出版社版式。

逐篇核对全文，而不是只读摘要或自动提取一次就确认：记录正文长度及统计口径/方法（排除摘要、参考文献、图注、SI；在线Methods单列，估算标注为估算）、页数/版式作为辅助、正文图和表分别计数、SI图表可取得时另计、引用数量及口径、章节/证据组织和图表作用。组合图计一张，面板可另记；多格式和同一论文不同版本不重复计数。引用优先核对主稿去重实引数；只取得参考文献表条目数时明确标注，不能当作同一指标混算。每项保留页码/章节/图表号等定位；缺失为未知，不填0，不推测未取得的SI。不同语言、文类或长度口径先分开，不直接合并平均。

两组分别汇总有效样本数、中位数、四分位范围及明显异常；各指标的有效样本数可能不同，报告原因。目标期刊组是主要参照，其他期刊组用于检验领域适用性；有明显分歧先解释文类、篇幅或证据差异，不把20篇一锅平均。官方当前投稿要求优先于已发表范例，期刊上限不是配额。由本稿真实内容给出正文体量、图/表及引用的建议范围和取舍，不能把样本中位数、上四分位或最大值变成硬性门槛。

完整对照明细留在已有范例记录；写作阶段新增或修正内容可记于 `source_verification/journal_benchmarks.md`，引用原记录而不复制整套库。writing_plan只保留两组目标/已下载/已核对数量、来源记录路径、关键分布、对本稿的影响和缺口。不得改写冻结的输入交接。分批获取、核对并保存接续，不把20篇全文同时塞进上下文；此处是全文结构与指标核验，不要求逐篇双语翻译或冒充整篇科学精读。选中的科学证据仍按原文核验要求单独处理。

下载受限或可比样本不足时保存失败原因、替代候选与未完成项，按可比性补位；目标刊缺额不能用其他期刊充数，不以便利获取替代筛选标准。继续有依据的临时方案与独立正文，但本项保持未完成并标明样本偏差，不能因脚本PASS就声称完成对照。基于完整样本确定方案，或在不可得时明确剩余缺口及对决策的限制；不反复尝试条件未变的失败路线。

这些论文是写作参照，不自动变成本文应引用的20篇，也不替代系统综述检索。引用仍按实质用途选择。可从已核对样本中选少量最适合的图作精细视觉基准；这不减少两组全文核对的目标。目标期刊或文类变化时只更新受影响样本和方案，恢复时复用已有文件，不重复下载或倍增目标。
