# 文献覆盖与引用安排

制定 writing_plan.md 时，结合每节实际论证检查基础与背景、直接竞争工作、方法来源、结果比较及不同结论/适用边界。只选与本文有关的维度，复用已核实文献库中的独立证据；交接中的核心文献不是引用上限，也不默认每个论点只留一篇。新增引用应提供支撑、比较、归属或限制信息，不能只增加篇数。

引用目标由用户要求、论文类型和实际证据需求决定，不预设统一篇数或倍增要求。若用户要求将已有稿件引用翻倍，以本轮扩充开始前的完整稿件为基线，在方案中一次记录版本/路径、统计口径、去重实引数 N0 和目标 2N0；其他明确目标按用户要求记录。后续继续写作、局部修改和下游处理沿用这个目标，不重新翻倍，也不在每次调用本 Skill 时重复发起扩充。全新稿件可用用户指定的可比旧稿作为基线；没有基线时，根据论文类型、领域、目标期刊和实际章节证据需求提出有依据的目标范围，在早期方案中说明，不能虚构 N0、把早期样稿当完整基线或声称已实现翻倍。

默认比较主稿（含图表说明）实际引用的不同文献数，SI 单列并记录全稿并集；若用户明确指定其他口径则前后一致。按 DOI 或核实后的文献信息去重，同一工作的预印本/正式版本通常计一次。重复调用、不同 citation key、只入库未引用或仅下载的论文不增加实引数；不能把引用集中移入 SI 来满足正文目标。

按章节推进时先查已有库及引文链，再按明确的章节/主张缺口分批补查，记录查询与筛选依据。新增来源须核实书目信息并读到支撑所引陈述的原文位置；摘要筛选不能冒充全文证据，具体数值、方法、争议和强综合按原文核验规则处理。不要无差别重读整个库，也不要把补文献变成重新选题。若新证据改变核心主张或暴露必要研究缺口，按现有影响与交接规则处理。

引用与相关论述一起自然整合，保留章节比例和论证重心，不为计数堆砌括号、泛泛背景或相互重复的描述。数量目标不允许引入无关、未读、重复或虚构文献。明确的期刊上限、有效证据不足或覆盖已充分且剩余来源不能增加实质支持时，记录实际数量、剩余差距及依据；不能默默降低目标或标记为已达成，必要的目标取舍交给用户，独立章节仍可继续。

通读全稿时在现有 content_check 记录基线/目标、主稿/SI/并集实引数、覆盖缺口及处理结果，供审稿复核；不另建引用配额台账。阶段就绪仍依照原规则，不以数量代替证据和语义检查，未解决的扩充目标也不能被脚本 PASS 掩盖。方案变化刷新受影响的锁和检查，不改写冻结的输入交接包。
