# Specialist scope and routing
scripts/routes.py resolves installed skill first, then the bundled Nature Skills
vendor (pinned commit in module/vendor/upstream-lock.json). Do not
copy engines or modify their upstream rules. Report missing specialist explicitly.

nature-writing: primary engine; task=manuscript only, paper_type mapping in manifest,
current section(s), requested language and real journal/generic. Read its manifest,
always_load and selected fragments. Reuse argument, section playbooks, Results
classification/allocation, claim repetition, terminology, journal-aware drafting.
Its broad submission/reviewer routes are OUTSIDE this Stage 2 contract.
nature-reader: locate original selected content using appropriate source-format
rules; scoped extraction/verification request, not indiscriminate full retranslation.
nature-figure: approved standalone briefs, actual data/assets, saved backend and its
own rendered QA; do not invent outputs or substitute AI for experimental evidence.
nature-ref-verifier: verify missing/changed metadata against authoritative sources.
nature-citation: only explicit Nature/CNS scope when it truly fits; no automatic
CNS-only filter on general/engineering manuscripts.
nature-academic-search: bounded lookup for documented section/claim coverage gaps;
preserve query/source and screening decisions, following citation-planning.md.

The router refuses other specialist names. Routes produce paths/instructions, not
fictional execution results. The Agent must actually read and apply the specialist.
If a real skill call requires unavailable credentials or user approval, follow that
specialist's contract, explain the exact blocker and continue independent tasks.
