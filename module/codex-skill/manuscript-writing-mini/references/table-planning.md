# 表格简报
默认 templates/table_brief.yaml 用于简单表：目的、所在章节、准确行列与单位、数据来源、可编辑数据路径、主文/SI位置和图注。
复杂跨研究比较、统计汇总或逐单元来源映射使用 table_brief_full.yaml，说明排序、缺失值、统计口径与来源。简化字段不允许省略科学含义。
保留 table source、最终表、图注及资产台账；实际使用的文献数字需回查原文。表格制作可随章节进行，不强迫先做完全部表。
数量与正文/SI安排沿用全篇图表方案。按期刊适用样式和可比论文组织列顺序、分组、单位、精度与注释，核对最终宽度下的阅读负担；过宽时先精简重复列或调整信息安排，不靠缩小字号硬塞，也不为增加表数拆开同一比较。

比较表只并列口径可解释的属性；异质指标保留各自定义、单位和验证条件，不拼成统一性能排名。只有存在明确评价准则及证据时才赋予成本、成熟度或优劣等级；否则列出实际部署条件和已报告验证。表格不为凑行列或视觉对称增加无证据字段。
