# 写作mini
调用 `$manuscript-writing-mini`，从蓝图/蓝图mini的真实交接材料继续。完整克隆本仓库并按根目录 README 安装。
新项目只需一份 writing_plan.md 加输入审计；先按全篇科学问题规划图表覆盖与数量；表达充分的简单图表用 compact-v1，复杂图保留 full，不以精简记录降低信息表达。旧版规划仍可读，原版不保证接受 mini 简报；审稿按不变的 Markdown、账本、资产和来源接口接收。
脚本使用 Python 3.11+，`scripts/manuscriptctl.py --help` 查看原有命令。共享 workflow-contract 与内置 vendor 随仓库提供。真实学术效果和远程压缩稳定性需实际使用检验。
