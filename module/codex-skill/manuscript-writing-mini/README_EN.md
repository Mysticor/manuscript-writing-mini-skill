# Manuscript Writing Mini

Turn a research evidence handoff into a complete Markdown draft using a concise writing
plan, an early representative section, and incremental text/figure collaboration.
Preserve source verification, numerical traceability, evidence boundaries and review handoff.
See SKILL.md for workflow details; no formal peer review or publication typesetting here.

Use Python 3.11+ and the repository requirements. Nature specialists and the shared
state library are bundled; optional installed specialist versions can override them.
A route resolves instructions, not evidence that an agent actually executed them.
See the repository README for installation, synthetic tests and optional downstream tests.
